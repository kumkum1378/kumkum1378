### 2. [`quantum-vqe-benchmarks`](https://github.com/kumkum1378/quantum-vqe-benchmarks)
*Variational Quantum Eigensolver (VQE) and quantum circuit state tomography in Python.*
- Benchmarked molecular ground-state energy estimations using **Qiskit** and **QuTiP**.
- Automated evaluation suites for model-generated quantum gate synthesis and noise mitigation routines.

- Slurm HPC integration with automated regression test suites and convergence validation scripts.

### 4. [`frontier-physics-cot-benchmarks`](https://github.com/kumkum1378/frontier-physics-cot-benchmarks)
*500+ graduate-level reasoning problem sets for frontier AI model training.*
